# My Personal Website

## ICT251 Web Technologies - Activity 3

This is my personal website created for ICT251 Web Technologies at
Mulungushi University.

The website was developed using HTML5, CSS3 and JavaScript. It contains
information about me, my hobbies, my learning plan, photos, multimedia,
projects and a contact form.

## Website Sections

The website contains the following sections:

- About Me
- My Hobbies
- My Learning Plan
- Photos
- Media
- My Projects and Skills
- Contact Me

## Technologies Used

The following technologies were used to develop the website:

- HTML5
- CSS3
- JavaScript

## JavaScript Features

The website contains four interactive JavaScript features.

### 1. Contact Form Validation

The contact form checks:

- Name
- Email address
- Message

The form rejects empty or whitespace-only information and checks whether
the email address has a valid format.

The form displays a validation result without sending information to a
server.

### 2. Expandable Project Details

The Projects and Skills section contains "Show Details" buttons.

When a user clicks the button, JavaScript displays the project
description. The button changes to "Hide Details" when the information
is displayed.

### 3. Photo Gallery Viewer

The website includes a photo gallery viewer with:

- Previous button
- Next button

The buttons allow the user to move between the available photographs.
The buttons are disabled when the beginning or end of the gallery is
reached.

### 4. Theme Switch

The website includes a theme switch that allows the user to change
between:

- Light Theme
- Dark Theme

This feature is controlled using JavaScript.

## How to Test the Website

1. Open the `index.html` file using Visual Studio Code.
2. Start Live Server.
3. Open the website in a web browser.
4. Test all navigation links.
5. Test the project "Show Details" buttons.
6. Test the contact form using valid and invalid information.
7. Test the Previous and Next photo buttons.
8. Test the Light/Dark Theme button.
9. Test the video and audio controls.
10. Resize the browser window to check the responsive design.
